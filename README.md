# Lampa Anime Online

Плагин для просмотра аниме в Lampa. Текущая версия — 1.12.0.

Кнопка «Аниме онлайн» появляется на странице фильма/сериала (и в контекстном меню карточки), затем предлагает выбрать источник.

## Источники

| Источник | Токен | Как воспроизводится |
| --- | --- | --- |
| AniLibria | не нужен | прямые HLS-потоки 480p/720p/1080p в штатном плеере Lampa, последовательный плейлист серий |
| YummyAnime.TV | не нужен | плеер Kodik открывается отдельным полноэкранным окном внутри Lampa |
| YummyAnime | не нужен (поле для токена есть) | то же окно; серии, озвучки и плееры берутся из `api.yani.tv` — Alloha, Kodik, CVH, Sibnet |

## Почему Kodik и другие плееры открываются отдельным окном

Прямой поток из Kodik получить нельзя:

- `kodikplayer.com` не отдаёт CORS-заголовки, поэтому XHR из браузера Lampa блокируется;
- через CORS-прокси служебный эндпоинт Kodik `/ftor` отвечает `500` (запрос проходит только из настоящего браузера);
- если подставлять в запрос `bad_user=true`, Kodik отвечает `500` гарантированно.

Поэтому плеер встраивается как iframe — iframe не подчиняется CORS. Проверено: из чужого origin нормально открываются и играют Alloha (`alloha.yani.tv`), Kodik (`kodikplayer.com`, в том числе `…/season/<id>/<hash>/720p?episode=N`), CVH (`ru.yummyani.me/iframeCVH.html`) и Sibnet (`video.sibnet.ru/shell.php`).

Сверху окна узкая полоса с названием и кнопками:

- **В плеер** — передаёт фокус внутрь плеера, чтобы им можно было управлять пультом;
- **Назад** — закрывает окно (равнозначно кнопке Back на пульте).

## Установка

Lampa → Настройки → Расширения → Добавить плагин, указать ссылку:

```text
https://cdn.jsdelivr.net/gh/tverzar/lampa-anime-online@main/anime_online.js
```

Резервные варианты:

```text
https://tverzar.github.io/lampa-anime-online/anime_online.js
https://raw.githubusercontent.com/tverzar/lampa-anime-online/main/anime_online.js
```

raw-ссылка отдаёт файл с `Content-Type: text/plain` и держит кэш десятки минут — если по ней подтянулась старая версия, обновите плагин позже или используйте jsDelivr.

## Настройки плагина

Раздел «Аниме онлайн» в настройках Lampa — поле для токена приложения YummyAnime (`X-Application`). Токен **не обязателен**: `api.yani.tv` отвечает и без него, заголовок уходит только если токен заполнен. AniLibria и YummyAnime.TV токена не требуют.

## Прокси Cloudflare

`worker.js` — CORS-прокси, через который плагин читает HTML и AJAX сайтов-источников (на телевизорах прямой запрос часто недоступен). Прокси принимает запросы только к доменам из белого списка: `yummyanime.tv`, `api.yani.tv` и домены Kodik. Адрес Worker прописан в самом плагине (константа `CORS_PROXY`).

## История версий

**1.12.0**

- Источник YummyAnime больше не требует токен и принимает все плееры API (`iframe_url`), а не только Kodik: Alloha, Kodik, CVH, Sibnet. При нескольких плеерах на серию выбирается более удобный для встраивания.
- Озвучки в списке сортируются по числу серий, в подписи видно используемый плеер.

**1.11.0**

- Kodik-источники (YummyAnime.TV, YummyAnime) открываются окном с плеером вместо попыток извлечь прямой поток — те не работали из-за отсутствия CORS и ответов `500` от Kodik.
- Удалён нерабочий разбор плеера Kodik (извлечение потоков, декодирование ссылок, список серий Kodik).
- Удалён источник Ani-Media: недоступен через Worker, без CORS для прямого запроса.
- AniLibria без изменений: поиск, серии, качество и плейлист работают как раньше.

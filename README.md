# Lampa Anime Online + Kino Online

Два плагина для Lampa в одном репозитории:

- **anime_online.js** (v1.12.1) — кнопка «Аниме онлайн» на карточке.
- **kino_online.js** (v1.0.0) — кнопка «Кино онлайн» на карточке: фильмы и сериалы.

## Установка

Lampa → Настройки → Расширения → Добавить плагин.

Аниме:

```text
https://tverzar.github.io/lampa-anime-online/anime_online.js
```

Кино:

```text
https://tverzar.github.io/lampa-anime-online/kino_online.js
```

Резервные адреса: `https://cdn.jsdelivr.net/gh/tverzar/lampa-anime-online@main/<файл>`
и `https://raw.githubusercontent.com/tverzar/lampa-anime-online/main/<файл>`.

Кэш: GitHub Pages обновляется за минуту-две после пуша, jsDelivr держит ветку
`@main` в кэше до нескольких часов, raw отдаёт `Content-Type: text/plain`.
Поэтому основной адрес — Pages; если в названии плагина старая версия,
подождите пару минут или возьмите резервный адрес.

## Кино онлайн (kino_online.js)

Источник — онлайн-кинотеатр **Kinokrad** (`kinokrad.cc`), токен не нужен. Что делает плагин:

1. ищет фильм по названию из карточки Lampa;
2. показывает найденные фильмы и сериалы (название и год);
3. открывает страницу фильма и вытаскивает из неё плееры;
4. если плееров несколько — предлагает выбор («Плеер 1», «Плеер 2» с именем площадки);
5. показывает плеер отдельным полноэкранным окном: сверху название и кнопки **В плеер** (передать фокус плееру для пульта) и **Назад** (закрыть, работает и кнопка Back).

Сериалы отдельного списка серий не требуют: у плеера свои переключатели сезона, серии и озвучки.

### Почему плеер открывается окном, а не прямым потоком

- Сайт не отдаёт CORS-заголовки, поэтому HTML читается через CORS-прокси (Cloudflare Worker из этого же репозитория, `worker.js`).
- Ссылки на плееры подписаны короткоживущими токенами, поэтому плагин каждый раз берёт их со свежей страницы фильма.
- Плееры Alloha и родственные CDN отказывают, если запрос пришёл **без Referer** (ответ «запрашиваемый контент не найден»). В Lampa страница отдаётся с `<meta name="referrer" content="never">`, поэтому у окна с плеером принудительно выставлено `referrerpolicy="unsafe-url"`. Без этого ни один такой плеер в Lampa не запускается — с этой правкой запускается.

## Аниме онлайн (anime_online.js)

| Источник | Токен | Как воспроизводится |
| --- | --- | --- |
| AniLibria | не нужен | прямые HLS-потоки 480p/720p/1080p в штатном плеере Lampa, плейлист серий |
| YummyAnime.TV | не нужен | плеер Kodik открывается окном внутри Lampa |
| YummyAnime | не нужен (поле для токена есть) | то же окно; серии, озвучки и плееры берутся из `api.yani.tv` — Alloha, Kodik, CVH, Sibnet |

Прямой поток из Kodik получить нельзя: `kodikplayer.com` не отдаёт CORS-заголовки, а через прокси его эндпоинт `/ftor` отвечает `500`. Поэтому плеер открывается как iframe.

## Прокси Cloudflare

`worker.js` — CORS-прокси, через который плагины читают HTML и JSON источников (на телевизоре прямой запрос часто недоступен). Прокси принимает запросы только к доменам из белого списка: `api.yani.tv`, `yummyanime.tv`, `kinokrad.cc`/`kinokrad.co`, `kinogo.ai`/`kinogo.zone`, `baskino.me`, домены Kodik. Адрес Worker прописан в плагинах (константа `CORS_PROXY`).

## Что проверено

- Поиск и страницы фильмов Kinokrad разбираются, плееры извлекаются, в Lampa открывается плеер «Дублированный 4K» и видео играет.
- AniLibria: «Наруто Ураганные хроники» → 131 серия, HLS 200.
- YummyAnime: «Боруто: Новое Поколение» → 13 озвучек, 293 серии, плеер Kodik играет выбранную серию.
- Встраиваемость плееров проверена загрузкой iframe со стороннего сайта: Kodik, Alloha, CVH, Sibnet — работают.

## Ограничения

- Kinokrad-плееры подписаны на домен площадки: если сайт переедет или сменит плеер, потребуется правка извлечения ссылок.
- Источники пиратские, реклама и доступность зависят от площадок.
- AniLibria — единственный источник с прямыми потоками, все остальные играют в окне-iframe.

**kino_online 1.0.0**

- Первый выпуск: поиск по Kinokrad, выбор фильма, извлечение плееров из страницы, окно с плеером, автоматическая подстановка параметра `d=<домен площадки>`.
- Диагностирован и обойдён запрет на отсутствие Referer (`referrerpolicy="unsafe-url"`).

**anime_online 1.12.1**

- Окну с плеером добавлен `referrerpolicy="unsafe-url"` — часть плееров не отдавала видео из-за политики `referrer: never` в самой Lampa.

**anime_online 1.12.0**

- Источник YummyAnime больше не требует токен и принимает все плееры API (`iframe_url`), а не только Kodik: Alloha, Kodik, CVH, Sibnet.
- Озвучки сортируются по числу серий, в подписи виден используемый плеер.

**anime_online 1.11.0**

- Kodik-источники (YummyAnime.TV, YummyAnime) открываются окном с плеером вместо попыток извлечь прямой поток.
- Удалён нерабочий разбор плеера Kodik и источник Ani-Media.

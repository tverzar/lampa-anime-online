# Lampa: Аниме онлайн + Кино онлайн (HDrezka прямым потоком)

Три части в одном репозитории:

- **anime_online.js** (v1.13.0) — кнопка «Аниме онлайн» на карточке (AniLibria, YummyAnime, YummyAnime.TV). На новом сайте (YummyAnime.TV) озвучка и серия выбираются в Lampa, а видео играет её собственный плеер: сервис на VPS отдаёт прямые HLS-ссылки плеера Kodik.
- **kino_online.js** (v2.0.0) — кнопка «Кино онлайн»: фильмы и сериалы **HDrezka прямым HLS-потоком**; если сервер недоступен — запасной источник Kinokrad (плеер окном).
- **kino_extractor.py** + **worker.js** — серверная часть: экстрактор HDrezka на VPS и CORS-прокси/мост на Cloudflare.

## Установка плагинов

**Одна ссылка на всё** — в Lampa → Настройки → Расширения → Добавить плагин:

```text
https://tverzar.github.io/lampa-anime-online/online_all.js
```

`online_all.js` — загрузчик: подтягивает `anime_online.js` и `kino_online.js` с GitHub Pages,
а если Pages недоступен — те же файлы с jsDelivr. Обе кнопки («Аниме онлайн» и «Кино онлайн»)
появляются на карточке.

Если нужен только один плагин — адреса по отдельности:

```text
Аниме: https://tverzar.github.io/lampa-anime-online/anime_online.js
Кино:  https://tverzar.github.io/lampa-anime-online/kino_online.js
```

Резерв: `https://cdn.jsdelivr.net/gh/tverzar/lampa-anime-online@main/<файл>`.

Диагностика (не для просмотра, а чтобы найти виновника зависаний): `slow_check.js` — плагин, который уведомлением показывает запросы, что не отвечают или тянутся дольше 4 секунд:

```text
https://tverzar.github.io/lampa-anime-online/slow_check.js
```

Кэш: GitHub Pages обновляется за минуту-две, jsDelivr держит `@main` часами.
Если в названии плагина старая версия — подождите пару минут или перезайдите в раздел расширений.

## Как работает «Кино онлайн» 2.0.0

1. Кнопка **«Кино онлайн»** на карточке фильма.
2. Поиск по названию на HDrezka через свой экстрактор (см. ниже).
3. Выбор фильма или сериала (в подписи год и тип).
4. Выбор озвучки (у фильмов до 10 вариантов, у сериалов до 20).
5. Для сериалов — выбор сезона и серии.
6. Воспроизведение в **штатном плеере Lampa** (hls.js): без iframe, без рекламы чужих сайтов, переключение качества прямо в плеере.
7. Если экстрактор недоступен — плагин уходит на запасной источник **Kinokrad** (плеер открывается окном, как в версии 1.x).

## Серверный экстрактор: зачем он нужен

HDrezka закрыта тремя защитами, которые браузер телевизора обойти не может:

| Защита | Что происходит | Как обходим |
| --- | --- | --- |
| Антибот **Anubis** (proof-of-work) | Запрос без пройденного челленджа получает страницу-заглушку | Экстрактор решает `sha256(randomData + nonce)` с нужным числом ведущих нулей и получает cookie `techaro.lol-anubis-auth` |
| Гео-замок по `CF-Connecting-IP` | Не-РФ/СНГ адрес получает `success: true`, но `url: false` — потока нет | Экстрактор подставляет в этот заголовок **IP клиента** (адрес, с которого пришёл запрос плагина) |
| Привязка ссылки к IP клиента | CDN `stream.voidboost.one` отвечает 404, если манифест запрашивает «не тот» адрес | Видео качает **сам телевизор**: ссылка минтится под его адрес, и CDN видит тот же адрес |

Отсюда главное ограничение: **поток нельзя проксировать** через сервер — сервер только выдаёт ссылку.

### Ручки экстрактора

Все запросы идут через `/kino/<token>/`:

| Ручка | Параметры | Ответ |
| --- | --- | --- |
| `/health` | — | состояние, версия, IP заказчика |
| `/search` | `q`, `limit` | список фильмов и сериалов |
| `/info` | `url` | id, озвучки, сезоны, признак сериала |
| `/episodes` | `url`, `translator`, `season` | список серий выбранного сезона |
| `/stream` | `url`, `translator`, `season`, `episode` | ссылки на HLS по качествам и субтитры |

Пример:

```bash
curl "https://<адрес>/kino/<token>/search?q=Интерстеллар&limit=3"
```

### Развёртывание на своём сервере

```bash
# 1. сервис
install -m 755 kino_extractor.py /opt/kino-extractor/kino_extractor.py
echo '{"token": "СВОЙ_ТОКЕН", "port": 8791}' > /etc/kino-extractor.json
chmod 600 /etc/kino-extractor.json

# 2. systemd
cat > /etc/systemd/system/kino-extractor.service <<'UNIT'
[Unit]
Description=kino-extractor (HDrezka для Lampa)
After=network-online.target

[Service]
ExecStart=/usr/bin/python3 /opt/kino-extractor/kino_extractor.py --config /etc/kino-extractor.json
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
UNIT
systemctl enable --now kino-extractor

# 3. nginx: http на 80 и https на 8443
#    сертификат Let's Encrypt на имя вида 94.156.237.213.nip.io (webroot + certbot)
```

Адрес экстрактора задан в `kino_online.js` в массиве `EXTRACTORS`: первый — свой адрес
с точным IP клиента, второй — мост через Cloudflare Worker (`/kino/*` в `worker.js`,
он передаёт адрес клиента в заголовке `X-Kino-Client-IP`).

Cloudflare Worker **не может** обращаться по голому IP (ошибка 1003), поэтому в `worker.js`
сервис указан именем (`http://94.156.237.213.nip.io`), а не `http://94.156.237.213`.

## Аниме онлайн (anime_online.js)

| Источник | Токен | Как воспроизводится |
| --- | --- | --- |
| AniLibria | не нужен | прямые HLS 480p/720p/1080p в плеере Lampa, плейлист серий |
| YummyAnime.TV | не нужен | плеер Kodik окном внутри Lampa |
| YummyAnime | не нужен | то же окно; серии, озвучки и плееры из `api.yani.tv` — Alloha, Kodik, CVH, Sibnet |

Прямой поток из Kodik получить нельзя: нет CORS, а через прокси его `/ftor` отвечает 500.

## Прокси Cloudflare

`worker.js` умеет два маршрута: `/proxy?url=` — CORS-прокси для плагинов (только домены
из белого списка: `api.yani.tv`, `yummyanime.tv`, `kinokrad.cc`, `kinogo.*`, домены Kodik)
и `/kino/*` — мост к экстрактору на VPS для случаев, когда телевизор не может достучаться
до сервера напрямую.

## Что проверено

- HDrezka: поиск «Интерстеллар» и «Во все тяжкие», 10 озвучек у фильма, 5 сезонов и 16 серий у сериала, ссылки на HLS получены; манифест (82 КБ) и первый сегмент (201 КБ, `video/MP2T`) скачаны с домашнего IP — цепочка «экстрактор → CDN → клиент» рабочая.
- Плагин 2.0.0 в живой Lampa: поиск, `info`, `episodes`, `stream` проходят через экстрактор (оба адреса, с автопереключением на резервный).
- Kinokrad: разбор поиска и страницы фильма, плеер «Дублированный 4K» играет в окне.
- AniLibria: «Наруто Ураганные хроники» → 131 серия, HLS 200.
- YummyAnime: «Боруто: Новое Поколение» → 13 озвучек, 293 серии, плеер Kodik играет выбранную серию.

## Ограничения

- Качество без входа на HDrezka — **360p** (сайт отдаёт больше только аккаунтам).
- Ссылка на поток живёт ограниченное время и привязана к IP: плагин получает новую на каждый запуск.
- Если у телевизора DNS блокирует `voidboost.one` (бывает у провайдеров и у локальных антизапретов), манифест не загрузится — тогда остаётся запасной источник Kinokrad.
- Источники пиратские: доступность и реклама зависят от площадок.

## История версий

**kino_online 2.0.0**

- Новый основной источник — HDrezka через серверный экстрактор: поиск, озвучки, сезоны, серии и прямой HLS в штатном плеере Lampa.
- Добавлен `kino_extractor.py`: обход антибота Anubis, подстановка IP клиента в `CF-Connecting-IP`, выдача ссылок на HLS; развёрнут как systemd-сервис и доступен по https на 8443.
- В `worker.js` добавлен маршрут `/kino/*` — https-мост к экстрактору с передачей IP клиента.
- Kinokrad остался запасным источником.
